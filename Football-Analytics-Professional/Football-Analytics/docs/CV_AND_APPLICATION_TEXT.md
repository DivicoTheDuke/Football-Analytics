# Portfolio wording

Use these statements only after uploading the repository and understanding the implementation well enough to explain it.

## CV entry

**Football Analytics Platform – Independent portfolio project**

- Built an end-to-end Python platform that transforms football event data into analyst-facing products through a Streamlit dashboard, FastAPI service and automated HTML reports.
- Implemented data-quality controls, feature engineering, expected-goals modelling, calibration analysis, expected threat, passing networks, team metrics and player similarity workflows.
- Used pandas, NumPy, scikit-learn, SciPy, NetworkX and Plotly, with automated tests, Docker and GitHub Actions.
- Designed a provider-neutral data model and a tested StatsBomb-style adapter, documenting production requirements for data governance, monitoring and model validation.

## Short application answer

I built an end-to-end football analytics application for non-technical users. I defined the data model, generated and validated event data, engineered football features, trained and evaluated an xG model, implemented xT and player-similarity analysis, and exposed the outputs through an interactive dashboard, an API and automated reports. The repository includes tests, Docker, CI and model-governance documentation.

## Interview reminder

Be explicit that the bundled dataset is synthetic and the project is a portfolio reference implementation. Explain how you would validate definitions with analysts, connect licensed provider data, test models temporally and integrate outputs into video workflows before operational use.
