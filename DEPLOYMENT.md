# Roadmap

## Phase 1 – Portfolio baseline

Event ingestion, quality checks, xG, xT, match dashboard, passing networks, player similarity, API and tests.

## Phase 2 – Open-data validation

Add a StatsBomb Open Data adapter, temporal validation, richer shot context, possession-value benchmarking and public reproducibility notes.

## Phase 3 – Analyst workflow research

Interview analysts, map current workflows, test prototypes, measure time saved, document acceptance criteria and refine visual hierarchy.

## Phase 4 – Production engineering

Scheduled pipelines, authentication, model registry, observability, data lineage, feature versioning and deployment automation.

## Phase 5 – Advanced football intelligence

Tracking-data support, pitch-control models, off-ball runs, pressing structures, sequence embeddings, video links and uncertainty-aware recommendations.
